# SMETIKA Wiki — Schema

Конфигурационный документ для Claude Code: описывает структуру, соглашения и рабочие процессы для поддержания этой вики.

---

## Назначение

Эта вики — постоянный, накапливаемый артефакт знаний о проекте SMETIKA. LLM (Claude Code) пишет и поддерживает её; люди читают и задают направление. Вики строится на основе трёх слоёв по паттерну Karpathy:

1. **Raw sources** — код, конфиги, история коммитов (неизменяемы)
2. **Wiki** — этот каталог markdown-файлов (пишет LLM)
3. **Schema** — этот файл (SCHEMA.md)

---

## Структура директорий

```
wiki/
  SCHEMA.md         ← этот файл: конвенции и рабочие процессы
  index.md          ← каталог всех страниц (обновлять при каждом ingest)
  log.md            ← append-only лог всех изменений
  overview.md       ← обзор проекта верхнего уровня
  entities/         ← страницы конкретных компонентов
    landing-page.md
    n8n-workflows.md
    vps-backend.md
    integrations.md
  concepts/         ← страницы процессов и потоков данных
    lead-flow.md
    pdf-flow.md
```

---

## Конвенции страниц

Каждая wiki-страница начинается с YAML frontmatter:

```yaml
---
title: Название страницы
category: entity | concept | overview
updated: YYYY-MM-DD
sources: [список файлов/компонентов, на которых основана страница]
---
```

- Используй внутренние ссылки: `[[entities/n8n-workflows]]`
- Версии и конкретные значения (URL, ID, порты) указывай явно
- Противоречия между страницами помечай `> ⚠️ Требует проверки:`

## Операции

### Ingest (новая фича / изменение кода)

Когда в проект вносится значимое изменение:

1. Обнови соответствующие entity/concept страницы
2. Добавь запись в `log.md` с префиксом `## [YYYY-MM-DD] ingest | Описание`
3. Обнови `index.md` если добавились новые страницы

### Query (вопрос о проекте)

1. Прочитай `index.md` для навигации
2. Прочитай релевантные страницы
3. Синтезируй ответ со ссылками на страницы
4. Если ответ ценный — сохрани как новую страницу в `wiki/`

### Lint (периодическая проверка)

Проверь:
- Противоречия между страницами
- Устаревшие URL, ID воркфлоу, версии
- Orphan-страницы без входящих ссылок
- Ключевые концепции без собственных страниц
