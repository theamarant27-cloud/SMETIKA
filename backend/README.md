# Smetika Landing Backend

Express backend for the Smetika landing page lead form. It accepts multipart leads with an optional PDF, stores leads in Postgres, keeps files in private local storage, sends Telegram/email notifications, and exposes a password-protected admin UI.

## Features

- `POST /api/leads` for public form submission
- validation for text fields and PDF uploads
- rate limiting, honeypot, CSRF, secure cookies, and helmet headers
- Postgres-backed leads + session storage
- admin UI for login, lead list, lead details, status updates, and PDF download
- retention cleanup that purges stored PDF files after 30 days

## Quick Start

1. Copy `.env.example` to `.env`
2. Create a password hash:

```bash
npm run hash-password -- "your-strong-password"
```

3. Put the resulting hash into `ADMIN_PASSWORD_HASH`
4. Install dependencies:

```bash
npm install
```

5. Run the server:

```bash
npm start
```

Tables are created automatically on startup.

## Important Environment Variables

- `DATABASE_URL`: Postgres connection string
- `SESSION_SECRET`: random session secret
- `ADMIN_USERNAME`: admin login username
- `ADMIN_PASSWORD_HASH`: argon2 hash generated by `npm run hash-password`
- `PUBLIC_ORIGIN`: allowed CORS origin for the landing page
- `APP_BASE_URL`: public backend base URL used in admin links
- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`: enable Telegram notifications
- `SMTP_*`, `NOTIFICATION_EMAIL_TO`: enable email notifications

## Admin UI

- `/admin/login` - login page
- `/admin/leads` - lead list
- `/admin/leads/:id` - lead detail page

The same `/admin/leads` and `/admin/leads/:id` routes return JSON if the request prefers `application/json`.
